# Установка и обновление KITH Carbon Fields

[English](../installation.md) · [Оглавление](index.md)

## Установка

1. Откройте [GitHub Releases](https://github.com/KITH-web-studio/carbon-fields/releases) и скачайте `kith-carbon-fields-<версия>.zip` из раздела **Assets**. Это установочный архив со сборкой редактора и PHP-зависимостями. Пункт GitHub **Source code (zip)** содержит исходный код.
2. В WordPress откройте **Плагины → Добавить новый → Загрузить плагин**, выберите архив и нажмите **Установить**.
3. Активируйте **KITH Carbon Fields**.

KITH и оригинальный Carbon Fields используют одно пространство имён PHP. Если тема или другой плагин уже загружает Carbon Fields, настройте сайт так, чтобы он загружал одну копию. Тогда будет понятно, какая версия предоставляет API, в том числе `set_translation()`.

## Язык редактора

В KITH Carbon Fields входят русский и украинский переводы. Откройте **Пользователи → Профиль → Язык** в WordPress и выберите **Русский** или **Українська**. Если в профиле выбран язык сайта, плагин берёт его из **Настройки → Общие → Язык сайта**.

## Первое поле

Добавьте пример в `functions.php` темы или в плагин сайта. Если в файле уже открыт PHP, опустите строку `<?php`. KITH загружает библиотеку при запуске WordPress, а обработчик регистрирует поле перед открытием редактора.

```php
<?php
use Carbon_Fields\Container;
use Carbon_Fields\Field;

add_action( 'carbon_fields_register_fields', function () {
    Container::make( 'post_meta', 'Page details' )
        ->where( 'post_type', '=', 'page' )
        ->add_fields( array(
            Field::make( 'text', 'kith_page_subtitle', 'Subtitle' ),
        ) );
} );
```

Откройте страницу WordPress, заполните **Subtitle** в контейнере **Page details** и сохраните страницу. В шаблоне используйте имя поля из объявления.

```php
echo esc_html( carbon_get_post_meta( get_the_ID(), 'kith_page_subtitle' ) );
```

Следующий шаг — выбрать [контейнер](containers.md) и [тип поля](fields.md) под свои данные.

## Обновление

Если WordPress предлагает новую версию, обновите её через **Консоль → Обновления**. Плагин проверяет последний стабильный релиз GitHub и ищет установочный архив с соответствующей версией. За автоматическое обновление отвечают настройки WordPress. Успешная проверка кешируется на шесть часов. Кнопка **Проверить снова** запускает новую проверку.

Для обновления вручную загрузите новый ZIP через **Плагины → Добавить новый → Загрузить плагин** и выберите замену установленной версии, когда WordPress её предложит. После обновления откройте заново вкладки редактора и настроек, которые были открыты во время установки.

Перед обновлением рабочего сайта сделайте резервную копию базы и проверьте ZIP на копии с вашей темой, плагинами и данными. Для Polylang проверьте страницу настроек с переводами и одну переведённую запись.
