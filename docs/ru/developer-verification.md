# Проверка новых полей и PHP API

[English](../developer-verification.md) · [Методы](developer-api.md) · [Поля](structured-fields.md)

В отчёте указаны сценарии и окружения, в которых локально проверялась версия 3.6.11.26.

## Автоматические проверки

Финальный совместный набор: **95 тестов / 772 проверки**, успешно. Ещё **183 старых теста / 333 проверки** проверены изолированно по классам; один network-тест пропущен.

Совместный регрессионный набор охватывает новые API, составные поля и шаги формы, а также запись только изменений, ревизии, Polylang, REST, таксономии, двусторонние связи, список записей, размещение WooCommerce, кеш и обновления.

Новые сценарии находятся в:

- `tests/unit-tests/Helper/DeveloperApiTest.php`
- `tests/unit-tests/Field/StructuredFieldsTest.php`
- `tests/unit-tests/Container/WizardTest.php`

Старые тесты дополнительно запускались по классам. Их общий запуск в одном процессе ненадёжен: старые тесты меняют глобальный DI-контейнер, а аннотации `@expectedException` не обрабатываются PHPUnit 9. Изолированный запуск использовал адаптер этих ожиданий, без изменения рабочего кода. Проверка network/multisite пропущена в односайтовой среде.

| Сценарий | Результат |
| --- | --- |
| 1000 строк, три уровня комплекса и вложенные JSON-таблицы | Данные повторно прочитаны без потерь. Сохранение без изменений — 0 записей в метаданные, правка одного вложенного значения — 1 запись. |

## Проверки браузером

Проверена настоящая админка WordPress с таблицей на 1000 строк, серверным справочником из 500 вариантов и вложенными строками комплекса. Проверялись клавиатурный выбор и отмена, загрузка следующих страниц вариантов, независимость строк, пагинация таблицы, смена родителя дерева в обе стороны, перемещение меток, выбор/отмена/повторное открытие медиа, ошибки обязательных шагов, отмена удаления строки комплекса и сохранение с перезагрузкой.

Таблица выводит только 25 строк на страницу. Одно локальное измерение от ввода до следующего отображения составило 56 мс, включая расходы автоматизации; это не универсальная гарантия скорости. Восстановленная строка удержала подпись выбранного select и вложенную таблицу, соседняя строка — свои значения.

Проверены русские и украинские элементы. Штатная медиатека проверена на компьютере и ширине 390 px, включая системные светлые/тёмные предпочтения; WordPress сохраняет собственный светлый диалог. Отдельная тема диалога Carbon не добавлялась.

## Среда и ограничения

- WordPress 7.1.4 / PHP 8.4.4, активные WooCommerce и Polylang — проверки редактора и браузера.
- WordPress 5.8.1 / PHP 8.4.4 — сохранение/повторное чтение 1000 строк, нормализации и вложенных значений. Отфильтрованы устаревшие уведомления ядра; обхода транзакций/SAVEPOINT нет.
- Собраны development- и production-файлы. Проверены синтаксис PHP, примеры PHP в обоих руководствах, UTF-8 без BOM и соответствие PO/MO для русского и украинского.
- В редакторе Leaflet тайлы OpenStreetMap загрузились с HTTP 200. Проверены добавление вершин кликом, перетаскивание, удаление и восстановление сохранённого контура после перезагрузки. При блокировке запросов за тайлами контур оставался видимым, а координаты — доступны для редактирования.
- Не выполнялась сертификация для боевого сайта, multisite, балансировщика и постоянного объектного кеша. Прежние поля автоматически не мигрируются в новые JSON-форматы.
