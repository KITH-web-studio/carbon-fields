# Возможности KITH и решение проблем

[English](../kith-features.md) · [Оглавление](index.md)

## Большие формы записи

В подходящих комплексах с вкладками редактор выбранной строки и открытых вложенных строк загружается по мере выбора. При сохранении передаются значения всего комплекса. Если браузер поддерживает событие `formdata`, контейнеры записей отправляют собранные данные одним значением формы, даже когда в них сотни вложенных полей. При необходимости редактор использует обычные элементы формы.

Вертикальная раскладка упрощает навигацию по длинному списку. Короткий заголовок из значения самой строки помогает найти нужную. Оба параметра показаны в [примере повторяемых секций](complex-fields.md).

Со стандартным хранилищем метаданных и совместимыми хуками сохранение сравнивает значения формы с данными в базе и записывает отличия. Это касается как обычных полей, так и ключей метаданных для вложенных полей.

## Превью медиа

Поля изображений, файлов и галерей показывают превью в редакторе. SVG, которые уже доступны в медиабиблиотеке, могут отображаться как изображения. Правила загрузки SVG настраиваются отдельно в WordPress. Для видео показывается постер или превью, когда формат поддерживается. Для вывода на сайте см. [пример работы с медиа](fields.md#медиа-и-связи).

## Ревизии и поля переводов

Контейнеры записей с включёнными ревизиями сохраняют снимки полей вместе с ревизиями WordPress. При восстановлении снимка возвращаются значения полей, которые в него вошли. Восстановление полей, синхронизируемых через Polylang, обновляет их и в применимых связанных переводах. Требования к базе и правам перечислены в [руководстве по Polylang](polylang.md#требования-к-синхронизации).

Чтобы отключить ревизии Carbon Fields для конкретного контейнера записи, вызовите у него `set_revisions_disabled( true )`. Остальными ревизиями управляют настройки WordPress и типа записи.

## Обновление плагина

Самостоятельный плагин проверяет последний стабильный релиз в репозитории KITH на GitHub. В [руководстве по установке](installation.md) описано, как обновить список обновлений WordPress и как загрузить ZIP вручную.

## Решение проблем

| Что происходит | Что проверить |
| --- | --- |
| Контейнер не появился | Условия `where()`, тип записи или таксономию и права пользователя. |
| Функция чтения вернула пустое значение | Имя поля, ID объекта и регистрацию поля к моменту вызова. Для настроек темы проверьте текущий язык контента и общее значение. |
| Поля нет в ответе REST | Регистрацию поля, `set_visible_in_rest_api( true )` и правила доступа маршрута. |
| Редактор отклонил неполную форму | Откройте редактор заново, чтобы загрузить актуальные поля и скрипты. Если ошибка повторяется, проверьте сторонние интеграции редактора и ограничения сервера на размер формы. |
| Общее поле записи не сохраняется | Права на редактирование переводов, использование стандартного хранилища и требования к базе из руководства по Polylang. |
| WordPress не находит новый метод | Какая копия Carbon Fields загружена темой или плагином и какая версия KITH установлена. |
| WordPress не предлагает обновление | Обновите список и проверьте, что релиз отмечен как стабильный и содержит установочный ZIP соответствующей версии. |
