# KITH Carbon Fields

[Читать на русском](README.ru.md)

KITH Carbon Fields is a fork of [Carbon Fields by htmlBurger](https://github.com/htmlburger/carbon-fields), maintained and developed by KITH Web Studio. It adds developer-defined custom fields to WordPress posts, terms, users, comments, settings pages, menus, widgets, and blocks.

Download the installable `kith-carbon-fields-<version>.zip` asset from [GitHub Releases](https://github.com/KITH-web-studio/carbon-fields/releases) and upload it in **Plugins → Add New → Upload Plugin**.
