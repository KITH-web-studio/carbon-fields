# KITH Carbon Fields

[English](README.md)

KITH Carbon Fields — форк [Carbon Fields от htmlBurger](https://github.com/htmlburger/carbon-fields), который поддерживает KITH Web Studio. Плагин позволяет объявлять поля на PHP и добавлять их к записям, терминам, пользователям, комментариям, настройкам, меню, виджетам и блокам WordPress.

Установочный архив `kith-carbon-fields-<версия>.zip` доступен в разделе [GitHub Releases](https://github.com/KITH-web-studio/carbon-fields/releases). Загрузите его через **Плагины → Добавить новый → Загрузить плагин**.
